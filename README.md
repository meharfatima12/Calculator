#### 🧮 Python Calculator

#### 

A simple command-line calculator developed using Python.



##### 📌 About the Project



This project is a basic calculator that performs mathematical operations on two user-entered numbers.



The program allows users to perform addition, subtraction, multiplication, and division while handling invalid inputs and division by zero.



##### ✨ Features



\- Addition (+)

\- Subtraction (-)

\- Multiplication (\*)

\- Division (/)

\- Accepts decimal and integer inputs

\- Handles invalid user inputs using try-except

\- Prevents division by zero

\- Checks for invalid operations



##### 🛠️ Technologies Used



\- Programming Language: Python

\- Concepts Used: Conditional Statements, User Input, Exception Handling



##### 🎯 How to Use



1\. Enter the first number.

2\. Select an operation (+, -, \*, /).

3\. Enter the second number.

4\. View the calculated result.
